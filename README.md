# 人生重開機：性別認同與生物性徵互動敘事遊戲

一個用 React + Tailwind CSS 打造的教育性互動敘事遊戲，幫助玩家理解性別、生物性徵與性別認同之間的複雜關係。

**最新更新**：根據文章《「生理性別」沒有辦法幫助我們好好討論生物性徵》進行深度劇情重構。遊戲現在重點聚焦於**雙性人（Intersex）群體的真實經歷、未經同意的醫療決定、與身體自主權議題**。

## 🎮 遊戲特色

- **人生模擬**：5 章人生節點，每章多個選擇，影響四條指標
- **開局隨機抽卡**：6 種身體設定 × 6 種社會情境的組合
- **指標系統**：Understanding（理解）、Safety（安全）、Connection（連結）、Stress（壓力）
- **知識解鎖**：每個選擇解鎖相關教育卡片，共 19 張深度內容
- **多結局系統**：6+ 種敘事結局，根據玩家選擇與指標組合觸發
- **完全 RWD**：支援手機、平板、桌機
- **無後端依賴**：純前端應用，可直接部署

## 📋 遊戲內容架構

### 人生 5 章
1. **出生**：指定性別、醫療決定、戶籍登記
2. **幼年**：性別規範、育兒期待、日常規訓
3. **青春期**：身體變化、同儕壓力、醫療尷尬
4. **成年初期**：證件、就業、親密關係、隱私邊界
5. **轉折**：關鍵決定，導向 6+ 種結局

### 開局抽卡
**身體設定**（6 種）：
- 外觀典型「男性特徵」——但內在可能有多樣性
- 外觀典型「女性特徵」——但內在可能有多樣性
- **出生時外生殖器不明確（雙性人）** ⭐ **新重點**
- **全面雄性激素不敏感症（CAIS）** ⭐ **新重點** （如文章案例 Alicia Roth Weigel）
- 幼年期看似典型，青春期才顯現差異
- 生物性徵的混合組合

**社會情境**（6 種）：
- 保守家庭，性別規範明確
- 開明家庭，尊重個人差異
- 偏鄉醫療資源不足
- 城市資源豐富但社會標籤強
- 學校性別規範嚴格
- 同儕支持高，但家人態度保留

### 知識卡主題（19 張）⭐ **根據文章深化**

涵蓋性別與生物性的多個維度，**特別強調雙性人群體與醫療倫理**：

- **基礎概念**：「指定性別」的定義、生物性的多層次特性、為什麼二元分類不精準
- **雙性人群體** ⭐：Intersex 的定義與 40+ 醫療狀況、被塞進二元框架的困境、青春期經驗
- **醫療決定與倫理** ⭐：身體自主權、知情同意、未經同意的醫療暴力、「觀察與等待」方案
- **性別發展**：性別社會化、性別認同形成、性別表達的流動性
- **隱私與自主**：隱私邊界、選擇性揭露、醫療隱私、身體自主權
- **支持與倡議**：同儕支持、故事的力量、專業資源、接納與自決

### 結局系統（6+ 種）⭐ **融入醫療倫理敘事**

基於指標組合觸發，每個結局都反映一段特定的人生軌跡：
- **和諧共處**：接納身體複雜性，與過去醫療決定和解
- **覺醒時刻**：發現社會期待是根源，開始倡議
- **堅強的獨行者**：獨自承載醫療創傷，找到內在力量
- **社群的燈塔**：將個人經驗轉化為倡議與支持他人
- **知情與自主**：成為自己身體決策的主人
- **不確定中的成長**：接納身份探索是終身過程

## 🚀 快速開始

### 安裝依賴
```bash
npm install
```

### 開發模式
```bash
npm run dev
```
遊戲會自動在 http://localhost:5173 開啟

### 生產構建
```bash
npm run build
```
構建輸出到 `dist/` 資料夾

## 🎯 遊戲設計原則

1. **避免說教**：用情境與選擇呈現「被迫決策」與「制度摩擦」的真實感
2. **尊重隱私**：強調隱私邊界與知情同意的重要性
3. **無道德判斷**：每個選擇都有得有失，沒有「正確答案」
4. **多樣性視角**：展現性別、生物性、身份的複雜與流動
5. **包容性語言**：使用中性、尊重的敘事tone
6. **教育目標**：隱性傳遞性別多樣性、生物性複雜性與身體自主權的知識

## ⚠️ 內容提醒

本遊戲討論身體、性別認同與制度議題。內容不涉及露骨或不適切描寫，但涉及：
- 身體發育與青春期
- 性別與性的複雜性
- 醫療決定與隱私
- 社會規範與個人自主

建議 12 歲以上玩家使用，家長與教育工作者可用此作為性別多樣性教育的補充工具。
